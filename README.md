# Mohammed Akther S — Digital Marketing Executive Portfolio Website

A bespoke, high-conversion single-page portfolio website for **Mohammed Akther S**, Digital Marketing Executive with 6 months hands-on experience in **Meta Ads**, **Google Ads**, **AI-based Image & Video Creation**, and **SEO / Lead Generation**.

Directly inspired by the presentation deck architecture and luxury aesthetic of [poongodi-portfolio.online](https://www.poongodi-portfolio.online/).

---

## 🌟 Key Features

1. **Dual Presentation Experience**:
   - **Slideshow / Pitch Deck View**: Full-screen slide cards with animated transitions, keyboard arrow navigation (`←` / `→`, `Space`, `PageUp` / `PageDown`), floating bottom dock toolbar, and slide counters (`01 / 10`).
   - **Continuous Vertical Scroll View**: Long-form, responsive single-page layout with section badges (`01 / Cover`, `02 / About Me`), scroll-spy active indicators, and smooth anchor jumps.
   - **Instant View Switcher**: Switch between both views with a single click in the top navigation bar.

2. **10 Comprehensive Sections**:
   - **01 / Cover**: Mohammed's portrait with luxury gold border, cursive typography, specialization badges, and quick CTA buttons.
   - **02 / About Me**: Narrative connecting Computer Science background (B.Sc & M.Sc CS Pursuing) with high-ROI growth marketing.
   - **03 / Core Expertise**: 4 capability pillars (Meta Ads Mastery, Google Ads PPC, AI Creative Studio, SEO & Analytics).
   - **04 / Career Path**: Detailed timeline of agency internship at **KA Strategist** (Coimbatore) and freelance lead gen project at **Kalvippaathai** (Erode).
   - **05 / Meta Ads Deep-Dive**: Interactive multi-tab campaign explorer with live metrics (CTR, CPL reduction, lead qualification) and full-funnel architecture (TOF, MOF, BOF).
   - **06 / Google Ads & SEO**: PPC search campaigns, negative keyword strategies, and technical SEO audits.
   - **07 / AI Creative Studio**: 3 interactive smartphone mockups simulating viral AI video reels and multi-variant ad banners with play/pause animations.
   - **08 / Skills & MarTech Stack**: Categorized interactive tool pills (Meta Ads Manager, Google Ads, GA4, GSC, Midjourney, Runway, CapCut AI, Canva Pro) and competency bars.
   - **09 / Education & Credentials**: M.Sc Computer Science, B.Sc Computer Science, and KGISL Digital Marketing Certification.
   - **10 / Connect & Direct Hire**: Direct Email, Phone call, direct WhatsApp chat, downloadable CV, and interactive email composer that pre-fills Gmail.

3. **Interactive Modals & Printable CV**:
   - **Resume Modal**: Instant preview of Mohammed's resume with download option.
   - **Printable CV View (`resume-view.html`)**: Dedicated, clean resume page with print stylesheet for saving as PDF or printing.

## 🚀 How to Run Locally

### Option 1: Direct File Opening
Simply double-click `index.html` in your file explorer to open it in Google Chrome, Microsoft Edge, or any modern web browser. No server required!

### Option 2: Local HTTP Server (Recommended)
Open a terminal in this folder and run:

```bash
# Using Python:
python -m http.server 8080

# Or using Node.js:
npx serve .
```

Then visit: [http://localhost:8080](http://localhost:8080)

## 🌐 How to Deploy for Free

You can deploy this portfolio online in less than 2 minutes:

### Netlify (Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop the `mohammed-akther-portfolio` folder.
3. Your portfolio is live instantly with a free SSL certificate!

### Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside this folder and follow prompts.

### GitHub Pages
1. Create a GitHub repository (e.g., `portfolio`).
2. Push this folder's contents to the `main` branch.
3. Enable **GitHub Pages** in Repository Settings -> Pages.
